# منبع و مجوز داده

منبع اصلی: GroupLens / MovieLens  
صفحه مجموعه‌داده: https://grouplens.org/datasets/movielens/  
README نسخه کوچک: https://files.grouplens.org/datasets/movielens/ml-latest-small-README.html

طبق README رسمی، داده‌ها برای اهداف پژوهشی قابل استفاده‌اند؛ استفاده تجاری یا درآمدزا نیازمند اجازه قبلی است. در گزارش باید مقاله معرفی مجموعه‌داده ذکر شود و نباید تأیید پروژه توسط GroupLens یا دانشگاه مینه‌سوتا القا شود.

استناد:
Harper, F. M., & Konstan, J. A. (2015). The MovieLens Datasets: History and Context. ACM Transactions on Interactive Intelligent Systems, 5(4), 19:1–19:19. https://doi.org/10.1145/2827872

# گام دوم پروژه: آماده‌سازی داده برای سیستم پیشنهاد فیلم

## تصمیم پروژه
برای نسخه فعلی پروژه، دامنه اجرایی را «پیشنهاد فیلم» در نظر گرفته‌ایم و از مجموعه‌داده `ml-latest-small` متعلق به MovieLens / GroupLens استفاده می‌کنیم. این انتخاب برای شروع آموزشی مناسب است؛ چون هم امتیاز کاربران به فیلم‌ها و هم عنوان و ژانر فیلم‌ها را دارد.

## منبع داده
- صفحه رسمی: https://grouplens.org/datasets/movielens/
- توضیحات و ساختار نسخه کوچک: https://files.grouplens.org/datasets/movielens/ml-latest-small-README.html
- نشانی دانلود: https://files.grouplens.org/datasets/movielens/ml-latest-small.zip

مشخصات اعلام‌شده برای این نسخه:
- 100,836 امتیاز
- 9,742 فیلم
- 610 کاربر
- 3,683 برچسب متنی (tag)

این نسخه داده توسعه/آموزشی است. داده‌ها مربوط به بازه 1996 تا 2018 هستند؛ بنابراین نباید آن را نماینده فیلم‌های جدید یا سلیقه همه کاربران دانست.

## مجوز و نحوه نگهداری
طبق README رسمی GroupLens، استفاده پژوهشی و آموزشی با رعایت شرایط مجاز است؛ استفاده تجاری یا درآمدزا بدون اجازه قبلی مجاز نیست. در هر گزارش یا خروجی علمی باید منبع داده ذکر شود و نباید وانمود شود که دانشگاه مینه‌سوتا یا GroupLens پروژه ما را تأیید کرده‌اند.

برای احتیاط، فایل خام داده را در مخزن عمومی GitHub قرار نمی‌دهیم. اسکریپت این پروژه فایل را از منبع رسمی دریافت می‌کند و پوشه‌های داده در `.gitignore` هستند. اگر استاد خواست خود داده هم تحویل شود، پیش از انتشار عمومی، شرایط بازتوزیع را با متن مجوز رسمی تطبیق دهید.

## فایل‌های داده
### `ratings.csv`
هر ردیف یک امتیاز یک کاربر به یک فیلم است:
- `userId`: شناسه ناشناس کاربر
- `movieId`: شناسه فیلم
- `rating`: امتیاز از 0.5 تا 5 با گام‌های نیم‌ستاره
- `timestamp`: زمان ثبت امتیاز به صورت Unix timestamp

### `movies.csv`
هر ردیف مشخصات یک فیلم است:
- `movieId`: شناسه فیلم
- `title`: عنوان فیلم، معمولاً همراه سال انتشار
- `genres`: ژانرها با جداکننده `|`

### فایل‌های دیگر
- `tags.csv`: برچسب‌های متنی کاربران برای فیلم‌ها
- `links.csv`: شناسه‌های IMDb و TMDb

## روش آماده‌سازی
اسکریپت `scripts/prepare_movielens.py`:
1. فایل ZIP را از منبع رسمی دانلود و استخراج می‌کند.
2. ستون‌ها و نوع داده‌ها را کنترل می‌کند.
3. ردیف‌های ناقص یا امتیازهای خارج از بازه مجاز را حذف می‌کند.
4. برای هر زوج کاربر-فیلم، در صورت وجود رکورد تکراری، آخرین امتیاز زمانی را نگه می‌دارد.
5. امتیازهایی را که شناسه فیلم متناظر در `movies.csv` ندارند کنار می‌گذارد.
6. داده هر کاربر را بر اساس زمان مرتب می‌کند؛ 80 درصد قدیمی‌تر را برای آموزش و 20 درصد جدیدتر را برای آزمون کنار می‌گذارد. این جداسازی زمانی از مخلوط شدن آینده و گذشته در ارزیابی جلوگیری می‌کند.
7. فایل‌های پاک‌سازی‌شده و خلاصه آماری را در `data/processed/` ذخیره می‌کند.

## خروجی مورد انتظار
پس از اجرای نوت‌بوک یا اسکریپت:
- `data/processed/ratings_clean.csv`
- `data/processed/movies_clean.csv`

## اجرا
از ریشه پوشه پروژه:

```bash
python -m pip install -r requirements.txt
python scripts/prepare_movielens.py
```

یا نوت‌بوک `notebooks/prepare_movielens.ipynb` را از ریشه پروژه باز و سلول‌ها را به ترتیب اجرا کنید.

## محدودیت‌های شناخته‌شده
- داده‌ها قدیمی هستند و اطلاعات جمعیت‌شناختی کاربران را ندارند.
- امتیاز ثبت‌شده الزاماً معادل علاقه واقعی یا تماشای کامل فیلم نیست.
- مشکل شروع سرد برای کاربر یا فیلم جدید وجود دارد.
- داده‌ها نامتوازن‌اند؛ بعضی فیلم‌ها و کاربران امتیازهای بسیار بیشتری دارند.
- این مرحله فقط آماده‌سازی داده است و هنوز مدل نهایی پیشنهاددهنده را آموزش نمی‌دهد.

## تمرین مستقل جلسه سوم (lab2)
فایل اصلی استاد با نام `notebooks/lab2_pathfinding.ipynb` بدون تغییر نگهداری شده است. نسخه توسعه‌یافته آن با نام `notebooks/lab2_pathfinding_extended.ipynb` همان تمرین را حفظ می‌کند و چالش «موانع بیشتر» را به انتهای آن اضافه می‌کند. این تمرین مستقل از دیتاست پیشنهاد فیلم است و روی نقشه شبکه‌ای جلسه سوم اجرا می‌شود. در آن احتمال مانع بودن خانه‌ها از 0.10 تا 0.50 تغییر می‌کند و نسبت نقشه‌های بدون مسیر برای هر مقدار محاسبه می‌شود. اعداد نهایی باید با اجرای نوت‌بوک به دست آیند.
